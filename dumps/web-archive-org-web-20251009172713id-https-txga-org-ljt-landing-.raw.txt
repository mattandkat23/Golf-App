    var rows = Array.from(table.querySelectorAll('.tablerow')); // Get all table rows
    var today = new Date();
    today.setHours(0, 0, 0, 0); // Normalize today's date to midnight for accurate comparison

    rows.sort(function(a, b) {
        var dateA = parseDate(a.cells[1].textContent.trim());
        var dateB = parseDate(b.cells[1].textContent.trim());
        
        if (dateA && dateB) {
            var pastA = dateA < today;
            var pastB = dateB < today;
            if (pastA && !pastB) return 1; // Past events go to bottom
            if (!pastA && pastB) return -1; // Upcoming events go to top
            return pastA ? dateB - dateA : dateA - dateB; // Within same category, sort by closeness to today
        }
        
        if (!dateA && !dateB) return 0; // Both are TBD, no change
        if (!dateA) return 1; // TBD goes to the bottom
        if (!dateB) return -1; // Dates go before TBD
    });

    // After sorting, re-insert rows
    rows.forEach(function(row) {
        table.appendChild(row);
    });

    function parseDate(dateStr) {
        if (dateStr === 'TBD') return null; // Return null for "TBD" dates to handle in sorting
        var dateParts = dateStr.split('-')[0].trim().split(' ');
        var year = new Date().getFullYear(); // Assume the current year; adjust logic if necessary
        // Adjust year based on months having passed already
        var month = new Date(dateParts[0] + " 1, " + year).getMonth();
        if (month < today.getMonth()) year += 1;
        return new Date(`${dateParts[0]} ${dateParts[1]}, ${year}`);
    }

Players who have distinguished themselves in previous Legends Junior Tour events as well as NTPGA All American Tour and STPGA Prestige Tour competitions will be given priority over other players. Registration for each ‘Open’ event will begin approximately 10 weeks prior to the tournament start date (with the exception of the Winter Classic and Jimmy Demaret Junior Classic). Upon close of registration for each event, players with priority status will be placed in the event first. Any remaining spots in the field will be filled by players without Priority Status in the order registrations were received.</p>

<p>When registering for any ‘Open’ event, all players will be placed on the pending/wait list. A player will not be charged the tournament entry fee until they have been accepted into the tournament. At that point, the credit card on file will be charged the tournament entry fee. Please check the championship information page for specific eligibility requirements for each championship.<span style="font-weight: 400;"></span></p></div>

<p><span style="font-weight: 400;">The Legends Junior Tour uses three different entry procedures to fill &amp; finalize tournament fields based on the level of event. </span><b>All entry procedures to fill tournament fields are implemented immediately following the close of registration for the given event.</b><span style="font-weight: 400;"></span></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><b>Priority Entry System: </b><span style="font-weight: 400;">All </span><span style="font-weight: 400;">Open</span><span style="font-weight: 400;"> level Legends Junior Tour events, excluding the Alamo Shootout.</span><span style="font-weight: 400;"></span></li>

Any remaining spots in the tournament field, and any subsequent waitlists, will be filled by players without ‘priority status’ in the order registrations were received. </span><span style="font-weight: 400;">LJT Priority Entry System</span><a href="https://www.txga.org/ljt-pes?swcfpc=1"><span style="font-weight: 400;"><br /></span><span style="font-weight: 400;"><br /></span></a><span style="font-weight: 400;">* </span><b>Priority Player Overflow:</b><span style="font-weight: 400;"> In the event that there are more priority players than spots in the tournament field, order of entry amongst priority players will be determined by the order listed below; *</span></p>

<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">2023 &amp; 2024 LJT Champions</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">2023 &amp; 2024 All American Tour, and Prestige Tour Champions (Applies for Winter Classic – Spring Preview entries), 2024 All American Tour and Prestige Tour Champions (Applies for Flodder Financial Shootout – James A. Ragan Memorial entries).</span></li>

Ragan Memorial entries).</span></li>

<p><b>Exemption Based Entry: </b><span style="font-weight: 400;">Players who have earned an exemption into the given event will be added to the tournament field once they have completed the registration process. LJT staff will add registered exempt players on a weekly basis throughout the open registration period. Once the listed event registration period closes, any remaining registered exempt players will be added to the tournament field. The remaining non-exempt players will then be ranked according to their junior golf rankings (i.e. </span><a href="https://www.juniorgolfscoreboard.com"><span style="font-weight: 400;">Junior Golf Scoreboard</span></a><span style="font-weight: 400;">, </span><a href="https://rankings.golfweek.com/rankings/default.asp?T=world"><span style="font-weight: 400;">GolfWeek</span></a><span style="font-weight: 400;">, etc.). This ranked list will then be used to fill any remaining spots in the tournament field and establish the event waitlist. </span></p>
<p><b>First Come, First Served: </b><span style="font-weight: 400;">Entries will be added to the tournament field based on the order in which they are received. Once the event division or tournament field is full, players will be automatically placed on the waitlist based on the same process.</span></p>
<p><b>Event Waitlist Procedures</b></p>
<p><span style="font-weight: 400;">Waitlists for each event will be published on the respective tournament homepage and included in the initial event waitlist email to players. Each event waitlist will be updated throughout the time leading up to its respective event. The order of each event waitlist is determined below;</span></p>
<p><b>Priority Entry System:</b><span style="font-weight: 400;"> Event waitlists are determined by the order of registration for non-priority status players. In </span><b>Priority Player Overflow</b><span style="font-weight: 400;"> situations, the event waitlist will use the previously mentioned procedures to sort any remaining priority status players, followed by non-priority status players. </span></p>
<p><b>Exemption Based Entry:</b><span style="font-weight: 400;"> Event waitlists will be created according to the ranked list previously mentioned in the </span><b>Exemption Based Entry Procedures. </b></p>
<p><b>First Come, First Served:</b><span style="font-weight: 400;"> Once the event division or tournament field is full, players will be automatically placed on the waitlist based on order of registration.</span></p></div>

				<div class="et_pb_text_inner"><p><span style="font-weight: 400;">The Legends Junior Tour is committed to establishing a professional, competitive environment where the country’s best junior players can develop and demonstrate their skills. Along with this, we want to provide innovative resources and services to junior golfers in search of college scholarships. Junior golfers should be aware of the NCAA’s strict rules, so the following information is intended to help assist players and parents in this process.</span></p>
<p>&nbsp;</p>
<p><strong>RULES OF RECRUITING</strong></p>
<p><span style="font-weight: 400;">The following tips about the Division I recruiting process can be found on the NCAA’s Web site, </span><a href="https://www.ncaa.org/"><span style="font-weight: 400;">www.ncaa.org</span></a><span style="font-weight: 400;">.</span></p>
<p><span style="font-weight: 400;">When you start ninth-grade classes, you become a “prospective student-athlete.”</span></p>
<p><span style="font-weight: 400;">You become a “recruited prospective student-athlete” at a particular college if any coach or representative of the college’s athletics interests (booster or representative) contacts you (or any member of your family) about enrolling and participating in athletics at that college. Activities by coaches or boosters that cause you to become a recruited prospective student-athlete are: </span></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Providing you with an official visit;</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Placing more than one telephone call to you or any other member of your family; or</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Visiting you or any other member of your family anywhere other than the college campus.</span></li>
</ul>
<p><span style="font-weight: 400;">No alumni, boosters or representatives of a college’s athletics interests can be involved in your recruiting. </span></p>
<p><span style="font-weight: 400;">You (or your family) may not receive any benefit, inducement or arrangement such as cash, clothing, cars, improper expenses, transportation, gifts or loans to encourage you to sign a National Letter of Intent or attend an NCAA college. </span></p>
<p><span style="font-weight: 400;">Letters from coaches, faculty members and students are not allowed until June 15 of their sophomore year of high school (summer between sophomore and junior years). </span></p>
<p><b>TELEPHONE CALLS</b></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Phone calls from faculty members and coaches are not permitted until June 15 of your sophomore year (summer between sophomore and junior years). After this, a college coach or faculty member may call, text or email you (or your parents/legal guardians) as often as they would like. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Phone calls between you (or your parents) and a coach may begin after June 15 of your sophomore year (summer between sophomore and junior years). </span></li>
</ul>
<p><b>CONTACTS</b></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">A college coach may contact you in person, off the college campus, no more than three times on or after August 1 of your junior year (summer between sophomore and junior years). Any face-to-face meeting between a college coach and you or your parents, during which any of you say more than “hello” is a contact. Also, any face-to-face meeting that is prearranged or that occurs at your high school, competition or practice site is a contact, regardless of the conversation. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Coaches may not contact you off the college campus more than three times. A college coach may visit your high school (with the approval of your high school principal) only once a week during a contact period. </span> </li>
</ul>
<p><b>EVALUATIONS</b></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">An evaluation is any off-campus activity used to assess your academic qualifications or athletics ability, including a visit to your high school (during which no contact occurs) or watching you practice or compete at any site. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Institutions have seven permissible recruiting opportunities (contacts and evaluations) during the academic year, and not more than three of the seven opportunities may be in-person, off-campus contacts. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Once you sign a National Letter of Intent, you may be evaluated an unlimited number of times by the college with which you have signed. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Programs are limited to 45 days per school year for evaluations, and DI programs are restricted from off campus evaluations from Thanksgiving to New Year. </span></li>
</ul>
<p><b>OFFICIAL VISITS</b></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Starting September 1 of your junior year, you can have one expense-paid (official) visit per college. You may receive no more than five such visits. There are no limits to number of unofficial visits you may take. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">You cannot have an official visit unless you have provided the college your high school academic transcript and a score from a PSAT, an SAT, a PACT or an ACT taken on a national test date under national testing conditions. </span></li>
</ul>
<p><b>NCAA ELIGIBILITY CENTER</b></p>
<ul>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">At the beginning of your sophomore year, you should sign up for the NCAA Eligibility Center, which ensures that the minimum requirements to participate in NCAA athletics are met. This is required for all athletes wanting to play at NCAA institutions. For registration materials, contact your high school guidance counselor or call the NCAA at (319) 337-1492.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">For questions or more information on NCAA Rules and Recruiting Information, please call (317) 917-6222. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">To receive NCAA Eligibility Center registration materials from NCAA, please call (319) 337-1492 or visit https://web3.ncaa.org/ecwr3/register/CERTIFICATION </span></li>
</ul>
<p>&nbsp;</p>
<p><b>NCAA Eligibility Center Mailing Address:</b><span style="font-weight: 400;"><br /></span><b>NCAA Eligibility Center</b><span style="font-weight: 400;"><br /></span><b>P.O. Box 7136 </b><span style="font-weight: 400;"><br /></span><b>Indianapolis, IN 46207C</b></p>
<p>&nbsp;</p>
<p><b>NATIONAL LETTER OF INTENT</b></p>
<p><span style="font-weight: 400;">A National Letter of Intent is an agreement signed by the prospective student-athlete, parent or legal guardian and the athletic director. The agreement states that the institution agrees to provide the prospective student-athlete, who is admitted to the institution and is eligible for financial aid under NCAA rules, athletic aid for one academic year in exchange for the prospects agreement to attend the institution for one academic year. Also, other institutions agree not to recruit a prospective student-athlete once he/she signs a NLI. The prospective student-athlete will no longer receive recruiting calls and is ensured an athletic scholarship for one academic year once the NLI is signed.</span></p>

<p><strong>Code of Conduct</strong></p>
<p><span style="font-weight: 400;">The Legends Junior Tour takes great pride in the quality of its players, host facilities, and sponsors. The tour requires all members to adhere to a set of guidelines known as the Code of Conduct. The purpose is to help all Legends Tour participants grow and mature by understanding and accepting the consequences of their actions, both on and off the golf course.</span></p>
<p><strong>Violations of the Code of Conduct</strong></p>
<p><span style="font-weight: 400;">Any of the following actions by an LJT member at an event, non-LJT event or toward another LJT member anywhere, constitutes a violation of the LJT Code of Conduct:</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Unsportsmanlike conduct including abusive language, club throwing, cheating, disrespect of volunteers, officials and host staff, or abuse of the golf course.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Use of smoking or chewing tobacco products, drugs or alcohol.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Not adhering to the dress code while at the host facility. This includes during a practice round. (See below.)</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Physical damage to property or equipment including that of the LJT or the host facility.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Physical abuse, threat of physical abuse, verbal abuse, slander or libel towards other players, parents, host golf course staff or members, Legends Tour staff or volunteers in any medium.</span></li>
</ol>
<p><strong>Required Dress at the Host Facility</strong></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Hats/visors must be worn with brim forward.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Collared shirts or mock turtlenecks (host golf course permitting) must be worn and tucked in at all times.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Women’s fashion shirts without a collar must have sleeves.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Women’s fashion shirts must not rise above the belt line at anytime during the golf swing.</span></li>
</ol>
<p><strong>Prohibited Dress at the Host Facility</strong></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Tank tops, T-shirts </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Denim shorts, short-shorts, cut-off shorts, gym shorts, jeans</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Body Piercings</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Tattoos (must be covered)</span></li>
</ol>
<p><span style="font-weight: 400;">Failing to adhere to the Legends Junior Tour Code of Conduct can result in a one-stroke penalty after a warning, or for further violations or extenuating circumstances, disqualification from the event and possible rejection of entry for future LJT events.</span></p>
<p><span style="font-size: x-large;"><b>Tournament Eligibility Requirements</b></span></p>
<p><span style="font-weight: 400;">The Legends Junior Tour is open to male and female golfers ages 12-19. Those members who have graduated from high school may only play until September 1 of the season directly following high school graduation. Any member who has graduated high school and started college is not eligible to play in LJT events.</span></p>
<p><span style="font-weight: 400;">The Tour was founded to give the best players in the state of Texas a chance to compete against one another. We pride ourselves on conducting first-class events at some of the finest facilities in the state. Although the Legends Junior Tour does not have a Handicap limit, we do expect our players to play to the level of their competition. If a competitor shoots consecutive rounds over 95 in any given tournament, the player may receive a letter from the Championship Committee of the Legends Junior Tour and will not be allowed to compete in LJT events until further notice. The Tour will be responsible for determining when that player may return to competition on the Legends Junior Tour.</span></p>
<p><span style="font-weight: 400;">Players may sign up for any open Legends Junior Tour event, given they meet the eligibility requirements of the Tour and the individual tournament. For the Texas Junior Amateur, because it is one tournament with different divisions, players must choose one division to play in. A player cannot compete in multiple divisions for any tournament on the Legends Junior Tour. Individual tournament eligibility requirements can be found on the specific championship information page. Players must be a member of the Texas Junior Golf Alliance to compete on the Legends Junior Tour.</span></p>
<p><span style="font-size: x-large;"><b>LJT Gender Policy</b></span></p>
<p><span style="font-weight: 400;">The Texas Golf Association and Legends Junior Tour adopted a new gender policy for its championships. The policy is referred to in the Conditions of Competition set forth in the Eligibility section of entry applications for all relevant LJT championships beginning with the 2021 championship season. The policy sets forth the procedures by which a transgendered player may participate in a LJT championship. The policy seeks to assure fair competition for all entrants in a LJT championship.</span></p>
<p><span style="font-weight: 400;">To read the full LJT Gender Policy, </span><a href="https://txga.org/gender-policy/"><span style="font-weight: 400;">please click here.</span></a></p>
<p><span style="font-size: x-large;"><b>Tournament Procedures</b></span></p>
<p><strong>Tournament Acceptance Notice</strong></p>
<p><span style="font-weight: 400;">Players will be notified, via email, when they have been accepted into the tournament. All players will be placed on the pending list once they sign up and the LJT staff will move players into the field based on Tournament Exemptions and the </span><span style="font-weight: 400;">LJT Priority Entry System</span><span style="font-weight: 400;">. It is the player’s responsibility to log on to the website to check the starting field, write down their tee time, schedule a practice round, and secure hotel reservations.</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Players with exemptions must complete the registration process by the deadline to secure their spot in the field. </span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">A player will not be charged the tournament entry fee until they have been accepted into the tournament. At that point, the credit card on file will be charged the tournament entry fee.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Players that sign up are not guaranteed a spot in the tournament field. </span></li>
</ol>
<p><strong>Pairings/Starting Times</strong></p>
<p><span style="font-weight: 400;">Pairings will be sent out along with Player Information and Guidelines for the event. Check the tournament pages for specific details regarding the release of pairings and information. </span></p>
<p><strong>Alternates</strong></p>
<p><span style="font-weight: 400;">Alternates will be permitted onsite before the first round and players wishing to use the alternate procedure must check in with an LJT staff member and will be added based on order of signup. Players that didn’t sign up will be put in order based on when they check in with the LJT staff after those on the waiting/pending list. </span></p>
<p><strong>Course Yardage</strong></p>
<p><span style="font-weight: 400;">Tournament yardages will vary based on the following factors: strength of field, overall difficulty of the golf course and daily weather conditions. On average, the following yardages will be used:</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Boys 15-18 (6,700+)</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Boys 14 &amp; Under (6,200 – 6,400)</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Girls 15-18 (5,800-6,100)</span></li>
</ol>
<p><strong>Distance Measuring Devices</strong></p>
<p><span style="font-weight: 400;">In accordance with the Rule 4.3a, for all LJT Championships, tournaments, and qualifiers, a player may obtain distance information by using a device that measures distance or direction. If, during a stipulated round, a player uses a distance-measuring device that is designed to gauge or measure other conditions that might affect his play: measuring elevation changes or interpreting distance or directional information (such as using a device to get a recommended line of play or club selection based on the location for the player’s ball) the player is in breach of Rule 4.3a(1). Penalty for the first breach from single act or related acts: general penalty. Penalty for second breach unrelated to first breach: Disqualification.</span></p>
<p><strong>Travel &amp; Lodging</strong></p>
<p><span style="font-weight: 400;">Information about the host hotel, discounted room rate, telephone numbers, and directions to the hotel will be posted on the website on the championship’s Tournament Information page.</span></p>
<p><strong>Practice Round</strong></p>
<p><span style="font-weight: 400;">Players will be responsible for calling the host facility to schedule practice rounds. The practice rounds are optional and green fees are not included in the tournament entry fee. However, the Legends Junior Tour will attempt to negotiate a reduced rate for practice rounds at the host facility.</span></p>
<p><strong>Player Registration</strong></p>
<p><span style="font-weight: 400;">Due to Covid-19 guidelines, there will be no player registration prior to the first round. All players will receive their tee gifts following the first round in the scoring tent.</span></p>
<p><strong>First Round</strong></p>
<p><span style="font-weight: 400;">The Legends Junior Tour recommends that players always double-check their tee time. The penalty for failure to show up on time is two-strokes or possible disqualification (Please refer to USGA Rule 5.3a for more information).</span></p>
<p><strong>Second/Final Round</strong></p>
<p><span style="font-weight: 400;">After the completion of the first round, all competitors will be re-paired (by score and within their division) for the second/final round. Second and/or final round parings will be available approximately 1 – 2 hours after the conclusion of the first round of play. Pairings can be found on the website and will be emailed out to all participants.</span></p>
<p><strong>Ties</strong></p>
<p><span style="font-weight: 400;">In the case of a tie for first place in any division, the LJT will hold a hole-by-hole playoff to determine the division champion. Ties for awards will be decided by matching scorecards. The following procedure will be used until the tie is broken:</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Low final round score</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Low score for the final nine (9) holes</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Low score on holes #13-#18</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Low score on holes #16-#18</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Low score on #18</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Process repeated on front side</span></li>
</ol>
<p><b>Note</b><span style="font-weight: 400;">: The process of matching scorecards is used only to determine which player will receive the 2nd place trophy and exemptions, but will not affect the number of Player of the Year points awarded.</span></p>
<p><strong>Awards Ceremony</strong></p>
<p><span style="font-weight: 400;">At the conclusion of the tournament, the Legends Junior Tour will pass out awards in a safe manner.</span></p>
<p><span style="font-size: x-large;"><b>Withdrawal Policy</b></span></p>
<p><strong>Prior to Cancellation Date</strong></p>
<p><span style="font-weight: 400;">If it becomes necessary for a player to withdraw from a tournament that they have been accepted to play in, he or she may logon through GolfGenius and withdraw themselves or notify the tournament director. Once reviewed by the tournament committee and the withdrawal is accepted, a refund will be issued minus a $25 administrative fee. Players may also call the Legends Junior Tour office at (214) 468-8955 to cancel.</span></p>
<p><strong>After Cancellation Date</strong></p>
<p><span style="font-weight: 400;">If a player withdraws after the cancellation deadline date, which is 10 days prior to the start of the tournament, or if they No Show to an event, they are not entitled to an entry fee refund. The following are the only exceptions: A player is entitled to a refund minus a $25 administrative fee:</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">If a player qualifies for an AJGA event over the same dates.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">If a player qualifies for any USGA national championship over the same dates.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">If a player qualifies for any national competition that is affiliated with the Legends Junior Tour.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">If an injury is sustained leading up to the event. Documentation from a doctor is required.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">If a player has a death in the family.</span></li>
</ol>
<p><span style="font-weight: 400;">Refunds will not be issued to those who withdraw because of “double scheduling” or qualifying for any other kind of tournament other than those listed above.</span></p>
<p><b><i>Exeption</i></b><i><span style="font-weight: 400;">: Should a player have to withdraw due to having Covid-19 symptoms (please check the updated Covid-19 Championship Guidelines) prior to the first round, he/she will receive a full refund.</span></i></p>
<p><span style="font-weight: 400;">In an exceptional circumstance, a player may file a written appeal for a refund to the Legends Junior Tour Executive Committee through the Tournament Director. These appeals will be reviewed on a case-by-case basis.</span></p>
<p><strong>During the tournament</strong></p>
<p><span style="font-weight: 400;">Upon commencement of play, any withdrawals for reasons other than family or medical emergencies will not be considered acceptable. For example, withdrawing because of poor play or “being out of the running” is not acceptable. Players that “No Card” after a round of play will receive a warning from the Legends Tour and may:</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Be suspended from entering the next event or;</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Be withdrawn from the next event.</span></li>
</ol>
<p><span style="font-weight: 400;">Failing to start at your scheduled tee time is a disqualification under the USGA Rules of Golf, and will be denoted as such in the final results.</span></p>
<p><span style="font-size: x-large;"><b>Conditions of Competition</b></span></p>
<p><strong>Pace of Play</strong></p>
<p><span style="font-weight: 400;">See separate memorandum to players and official LJT scorecard for pace of play policy and tournament specific time charts.</span></p>
<p><strong>Out of Position</strong></p>
<p><span style="font-weight: 400;">A group will be out of position when it (A) completes play on a hole (replaces the flagstick or removes the ball when the flagstick is left in) later than the time scheduled in the time chart provided and (B) reaches a par 3 hole and the preceding group has left the next tee or fails to clear the tee of the par 4 hole before the preceding group has left the putting green, or arrives at the tee of a par 5 hole when the preceding group is on the putting green. Both (A) and (B) must occur for a group to be out of position.</span></p>
<p><strong>Timing</strong></p>
<p><span style="font-weight: 400;">When the Committee determines that a group (or individual) will be timed, all players (or a specified individual) in the group will be notified by a Referee. Players will have 40 seconds to play a stroke. The timing of a player’s stroke will begin when it is his/her turn to play and he/she can play without interference or distraction. Any time spent determining yardages will count as time taken for the next stroke. On the putting green, timing will begin after the player has been allowed reasonable time to mark, lift, clean, and replace his/her ball, repair his/her ball mark and other ball marks on his/her line of putt, and remove loose impediments on his/her line of putt.</span></p>
<p><span style="font-weight: 400;">Penalty for Exceeding 40 Seconds</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">FIRST OFFENSE – Informed of “Bad Time”</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">SECOND OFFENSE – One stroke penalty</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">THIRD OFFENSE – Two stroke penalty</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">FOURTH OFFENSE – Disqualification</span></li>
</ol>
<p><strong>Rulings/Other Incidents</strong></p>
<p><span style="font-weight: 400;">Should a ruling or other legitimate delay cause a group to lose its position, the group is obligated to regain its position within a reasonable time.</span></p>
<p><strong>Stopping and Resuming Play</strong></p>
<p><span style="font-weight: 400;">When play is suspended by the Committee for a dangerous situation, if the players in a match or group are between the play of two holes, they must not resume play until the Committee has ordered a resumption of play. If they are in the process of playing a hole, they must discontinue play immediately and not resume play until the Committee has ordered a resumption of play. If a player fails to discontinue play immediately, he is disqualified, unless circumstances warrant waiving the penalty as provided in Rule 5.7. Local Rule as prescribed in Section 8 of the Committee Procedures is in effect. Model Local Rule J-1.The signal for suspending play due to a dangerous situation will be a prolonged note of the siren.</span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Discontinuance of Play Immediately: One prolonged air horn note</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Discontinuance of Play: Three consecutive air horn notes, repeated</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Resume Play: Two short air horn notes, repeated</span></li>
</ol>
<p><span style="font-weight: 400;">All practice areas are closed during the suspension during a dangerous situation until the Committee has declared them open. </span></p>
<p><b>Note</b><span style="font-weight: 400;">: Players who practice on closed practice areas will be asked to cease doing so; failure to comply may result in a violation of the LJT Code of Conduct.</span></p>
<p><span style="font-size: x-large;"><b>Digital Media Use</b></span></p>
<p><span style="font-weight: 400;">The Legends Junior Tour reserves the right to use any competing player’s name, image and likeness in the promotion of LJT events and the tour. Use of media includes but is not limited to website publications, social media posts and tournament signage. </span></p>
<p><span style="font-size: x-large;"><b>LJT Spectator Policy</b></span></p>
<ol>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">In accordance with Rule 10.2a, spectators may not give players advice during their round. The definition of advice is “any verbal comment or action that is intended to influence a player in: choosing a club, making a stroke or deciding how to play during a hole or round.”</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Spectators should stay one shot ahead of the group they are following. This allows spectators to follow errant shots and help identify where the ball comes to rest. Spectators are allowed to aide in the search of lost golf balls.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Spectators walking with a group should stay on the cart paths. In the absence of cart paths, we ask that spectators stay in the rough. Please stay off fairways, tees and greens.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Spectators should not give rulings. Please seek an LJT Referee if the need arises.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Spectators are allowed to carry medicine, drinks, food, umbrellas, etc.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Spectators are asked to respect the host facility’s cell phone policy. If phones are allowed on the course, please turn ringers to silent or the vibrate mode.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Spectators are asked to adhere to the LJT and host facility’s dress code policy. This means no jeans, jean shorts, t-shirts, flip-flops, sweatpants or tank tops are allowed.</span></li>
<li style="font-weight: 400;" aria-level="1"><span style="font-weight: 400;">Transportation: Each player must carry his/her own bag and must not use or accept automotive transportation unless acting under the direction of an LJT referee.</span></li>
</ol>
<p><b>Note:</b><span style="font-weight: 400;"> If any of the following guidelines are perceived as broken by an LJT Referee, the player may be subject to penalty.</span></p>
